我在做什么

做 AI 算法与系统工程。所有工作背后其实是同一个问题:

系统如何知道自己什么时候不可信,并据此降级、保守化或拒答。

它展开成四条主线:

  • 退化条件下的可信度 —— 不确定性量化 / 失效识别 / 降级与回滚
  • 从感知到决策的闭环 —— 状态估计 / 持续内部状态 / 在线自适应
  • 智能体的工程闭环 —— 数据 / 训练 / 评测 / 部署 / 数据飞轮
  • 训练与推理基础设施 —— 分布式训练 / 推理加速 / 并发与延迟

技术主线怎么长出来的

算法竞赛与数学 → 深度学习与计算机视觉 → 大数据与 NLP → 大模型、Agent 与可信 AI。 这条线不是刻意规划的,是每一次「选择留下来」的结果。回头看去,早期那些看起来和 AI 无关的积累 (动态规划、概率统计、图论)后来都变成了地基。

如果只能留一句话,是这句:在真实业务里,模型的「可信」比「聪明」更重要。

公开产出

下面几个自建的小型可复现实验,都是能跑、能查、能被反驳的:

uq-state-estimation传感器退化下,状态估计的不确定性还可不可信
正常条件下两个滤波器无法区分;退化时朴素滤波器声称 95% 置信区间、实际只兑现 34.7%
table-structure-gnn无边框复杂表格的行列结构与合并表头复原
边级准确率 99.1% 时结构 F1 只有 0.551;一致性后处理把列分组 F1 提到 0.695
rag-eval-abstention让 RAG 学会说「我不知道」
拒答 18% 的查询后,精确率 0.633 → 0.755,幻觉率 0.367 → 0.200
floorplan-parsing户型图结构化解析(2018–19 方向的复现)
规则法平均 IoU 0.465 / 门 F1 0.06;逐像素学习法 0.804 / 0.47
reading-log学习日志:读了什么、搞懂了什么、还没搞懂什么
索引由脚本自动生成,重点是「还没搞懂」的部分
