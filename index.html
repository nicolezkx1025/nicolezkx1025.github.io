ROS系列项目 —— TurtleBot3 扩写版README

Posted on 2025-04-29

TurtleBot3 ROS package 的主要功能和核心组件：

主要功能：

  1. TurtleBot3 是一个小型、低成本、可编程的移动机器人平台
  2. 它提供了完整的 ROS（机器人操作系统）集成支持
  3. 主要用于教育、研究和开发目的

核心功能包（Packages）：

  1. turtlebot3_node：核心功能节点，负责机器人的基本控制和状态管理

    点击这里查看 turtlebot3_node 详细信息
    turtlebot3_node 的主要功能和核心节点：

    ► 主要功能：

    1. 作为 TurtleBot3 机器人的核心控制节点
    2. 负责与硬件（OpenCR 控制器）的通信
    3. 实现机器人的基本运动控制和传感器数据处理
    4. 提供里程计（Odometry）信息
    5. 管理机器人的状态和配置

    ► 核心节点和组件：

    1. 主节点（TurtleBot3）：

      • 位于 turtlebot3.cpp
      • 负责初始化机器人系统
      • 管理硬件通信
      • 处理传感器数据
      • 发布机器人状态信息

    2. 差速驱动控制器（DiffDriveController）：

      • 位于 diff_drive_controller.cpp
      • 实现差速驱动控制
      • 处理速度命令
      • 计算轮子转速

    3. 里程计节点（Odometry）：

      • 位于 odometry.cpp
      • 计算和发布机器人的位置和姿态信息
      • 基于编码器数据计算运动学信息

    4. DYNAMIXEL SDK 封装：

      • 位于 dynamixel_sdk_wrapper.cpp
      • 提供与 DYNAMIXEL 电机通信的接口
      • 处理电机控制和状态反馈

    5. 传感器处理：

      • 位于 sensors/ 目录
      • 处理各种传感器数据（如 IMU、激光雷达等）
      • 提供传感器数据接口

    ► 主要通信接口：

    1. 订阅：

      • 速度命令（cmd_vel）
      • 配置参数
      • 传感器数据

    2. 发布：

      • 里程计信息
      • 传感器数据
      • 机器人状态
      • 诊断信息

    ► 这个节点是整个 TurtleBot3 系统的核心，它负责：

    • 与硬件层的通信
    • 运动控制
    • 传感器数据处理
    • 状态管理
    • 提供上层应用所需的各种接口

    ► 通过这个节点，上层应用可以方便地控制机器人，获取传感器数据，实现各种功能。它是连接硬件和上层应用的桥梁，是整个系统的基础。


  2. turtlebot3_teleop：远程遥控功能包，用于手动控制机器人

  3. turtlebot3_navigation2：导航功能包，实现自主导航功能

其中，本地知识图谱检索的主题类别:

可以看出官网产品级，在后处理过程的修正会从法律、医疗、数理和自然语义的符号定义做出更具严谨性、完备性和合法合规的明确界定。因此，如果在问题在比较通用和普世的前提下，API服务和官网返回的结果不会太受到左子树B结点到E结点这一步的影响。

结果差异机制：

  1. 官网在处理长对话时会动态注入领域修正参数（如法律条款即时校验模块）
  2. API严格遵循请求参数配置，更适合需要确定性输出的工业场景
  3. 存在<0.5%概率的随机采样差异源于官网的实时热度衰减算法

DeepSeek的API服务和官网应用均基于同一核心技术架构开发，在核心能力上保持高度一致：

精度一致性验证：

  • 在第三方基准测试中（GSM8K、HumanEval等），两者的准确率差异小于0.5个百分点
  • 复杂代码生成任务结果哈希校验重合度超过98%
  • 数学证明题分步推导路径一致性达96%以上

极端场景容错率

  • 官网内置自适应熔断机制：在输入超过128K tokens（25万汉字，等效《平凡的世界》全本体量）时自动切换轻量化模型分支
  • API端严格按照请求规格执行，需开发者自行处理长文本分段

综上：

数据反映的效果接近一致：基于第三方基准测试数据，API服务和官网应用的核心模型在准确率上的差异确实保持在±0.5个百分点以内。

但从体感使用上存在使用差异：

  • 在赛博算命的时候，通过API服务得到的反馈结果通常更具积极的态势与较高的宜人性；
  • 在用作debug pilot的时候，还是搜索网页比较快，是习惯问题，更是现阶段AI的使用仍然达不到类似“脑机接口”或是全面代理接管的替代程度；
  • 在逆工程学习AI推理思路的时候，AI的思考过程通路基本一致；
  • 在文学方面，由于API的结构化输出，拟人度是低于官网效果的，若要给出像官网返回的结果即不失文采又具备结构化的表达，就需要在后处理的环节去进一步复现它的效果；
  • 非文学方面，API的结构化输出更占优势。

    题外碎碎念：

  • 我一直抱有一处怀疑，就是在超出人类经验和知识的部分，或在一些未关注到和验证的冷门领域，高宜人性的AI仍然会为了回答出问题而反馈出一个“幻觉”给期待着的人类。在文中流程图的，知识图谱的 过程性知识结点 到 技能策略图谱（如反证法应用场景结构）这部后处理过程，按照工程处理思路就是要写对于像弱智吧和脑筋急转弯这种题目的识别，有些另类的提问会是非常隐蔽的，对于不应该有答案的问题，最佳的反应是要先叼一下题目，而不是为了回答而回答。其实就是，要允许有一部分题，AI的最佳答案应该是 “我不清楚，因为我对于这道题的答案一定会是错的。与此同时，人，你也应该检查一下你的问题是不是有毛病呢。” 不然整体人类吸收到的幻觉和正确的知识也会跟着AI一起，混淆并同步提升。

「 量子破解倒计时：当《流浪地球》MOSS学会暴力穷举时，人类还剩多少安全密码？」

Posted on 2023-02-19 Edited on 2025-03-23

  起了一个噱头标题，但严肃来说，这里也是引用的马里兰大学帕克分校的密码学家 Jonathan Katz的说法。
后量子密码（PQC）破译一个少一个，就像人类在强人工智能面前终将逐步被替代，在最近大火的自然语音处理领域腾空出世也有迹可循，Bert被GPT替代，GPT被chatGPT替代。
重赏之下，破解这些曾经可靠的密钥只是时间问题。为什么想起来写一篇这样的选题，起因是对流浪地球2里的核密码破解的困难程度感到好奇。

  电影中使用550W超级量子计算机，对剩余核弹的破译时间也还需要700多个小时。在流浪地球的世界观框架下，MOSS同时具有Evil AIs和Angel AIs，所以这700多个小时是那部分Evil AIs有意为之，故意拖延时间的。
但是这也说明了破译足够有难度的密码也需要大量的时间。
  那么是什么决定了密码的破译难度呢？为了应对目前现代密码学基于经典计算机设计的加密技术在量子计算机面前不适用的威胁。
本着一颗好奇心，本系列文章将围绕美国国家标准与技术研究院（NIST）机构近年来研究的，对那些有潜力成为全世界可以采用的新标准算法进行笼统业余的粗略介绍。

  根据一种来自查理芒格的思维方式，凡事可以从反教材入手，我们可以初探一下一开始就败下阵来的算法有什么特点，以及如何避免这样的特点。

  2022年7月5日，NIST公布其后量子密码（PQC）标准化项目第三轮筛选的结果，并公布第四轮候选密钥建立机制的入选算法。
虽然SIKE因密钥和密文较小具有突出优势，以一度高性价比的可靠表现备受关注，NIST将在第四轮继续进行研究讨论，但在同年7月30日和8月8日，
SIKE分别被比利时鲁汶大学(KU Leuven)开发的名为Magma的程序和来自布里斯托大学团队设计的一种称为“挠点”(torsion point)的方法一一破解。
这其中最令人意想不到的是，SIDH是最早实用的基于同源的加密协议之一，而SIKE是它的实例化，这一算法怎么也算的上是21世纪的年轻新星，并且在它诞生的12年里一直给人留下安全性高，简洁高效的印象，这次却在1个月内被攻破两次。事出突然，那么SIKE的算法具体是什么呢，这次的攻击到底是使用了什么先进的数学方法。

  SIKE算法，全称Supersingular Isogeny Key Encapsulation, 一种基于SIDH，即超奇异同源 Diffie-Hellman公钥交换协议的实例。
Jao和Luca De Feo在一篇Towards Quantum-Resistant Cryptosystems from Supersingular Elliptic Curve Isogenies1提出，刊登在Post-Quantum Cryptography2一书，作者是台湾中央研究院的Bo-Yin Yang。
该方法可以概括为，假设Alice和Bob两人想要秘密交换信息，但是处于一个不安全的环境下。Alice和Bob抽象为两个图（graph），

####  Overview of SIDH:

    1. Public parameters: Supersingular elliptic curve E over F p2

      椭圆曲线 E 定义在 q=p2 ，p 是素数，其实我感觉这里field是GF有限域

      超奇异椭圆曲线定义：如果一条定义在 Fq 上的椭圆曲线 E 的自同态环在 Fq 的代数闭包上是不可交换的，那么这个椭圆曲线就被称为超奇异椭圆曲线。

      Isogenies同源定义：是指两条椭圆曲线之间的同态，即把一条椭圆曲线上的点映射到另一条椭圆曲线上。
