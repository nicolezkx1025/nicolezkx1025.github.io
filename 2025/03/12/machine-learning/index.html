机器学习:三大流派、偏差方差,以及"评估口径决定一切"

Posted on 2025-03-12
摘要:机器学习是 AI 的"正规军"。这篇把三大流派、偏差方差权衡、正则化讲扎实,再用工业落地经验说明:为什么评估口径比模型选择更重要。

一、三大流派:频率派、贝叶斯派、几何派

  • 频率派 / 优化派:把学习看成最小化损失。线性回归 → 最小二乘;逻辑回归 → 极大似然。核心工具是梯度。
  • 贝叶斯派:把参数当随机变量,求后验 $P(\theta|D)$。高斯过程、贝叶斯优化都属此列,天然带不确定性——这是我后来转向 UQ 的桥梁。
  • 几何派 / 核方法:把数据映射到高维再划边界。SVM 的核技巧 $K(x_i,x_j)=\langle\phi(x_i),\phi(x_j)\rangle$ 让我第一次理解"升维降难"。

三派不是对立的:逻辑回归既是最优化也是概率模型;SVM 与贝叶斯决策在特定条件下互通。理解三派,就理解了机器学习地图。

二、偏差-方差与正则:模型复杂度的哲学

  • 偏差高 = 欠拟合(模型太简单);方差高 = 过拟合(模型太复杂);
  • 正则化(L1/L2)就是在损失里加"复杂度税":$L = L_{data} + \lambda\|\theta\|$;
  • 交叉验证是估计"泛化误差"的标准手段——在测试集上调参,等于作弊,这是工业界最常见的隐性错误之一。

三、工业落地:评估口径决定一切

我在理财子做数据治理时,学到最痛的一课:再强的模型,如果没有可审计的评估口径,就上不了生产。具体三条:

  1. 训练/验证/测试三集严格分离,时间敏感数据要按时间切分(防未来信息泄漏);
  2. 指标要跟业务对齐:监管报送场景,假阴性比假阳性贵一百倍,所以只报准确率是耍流氓;
  3. 上线前必须 A/B:离线指标好 ≠ 线上效果好,分布漂移是常态。

四、从机器学习到大模型:哪些没变

  • 损失函数、优化器、正则化——没变,只是规模放大;
  • 过拟合 → 变成了"记忆训练集",所以有评测集的 held-out 纪律;
  • 评估口径——更严格了:大模型时代甚至要防"评测集被训练集污染"。

*参考来源:AiLearning(apachecn)、经典 ML 教材;本文为个人学习与金融落地经验的梳理。*
